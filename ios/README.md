# MAMA для iPhone

Ветка `claude/mama-ios` — разработка MAMA для iOS. Android-версия
продолжается в ветке `claude/mama-phone-lock-app-vzccj7`; эта ветка создана от
неё (v0.7.8), поэтому все продуктовые правила и общая логика уже здесь.

## Что переносится без изменений

- Продуктовые правила: `docs/MONETIZATION.md`, `docs/CORE.md` — серии 3/5/7,
  Restart 99/199/299 ₽, 30 дней после срыва, FLEX, «Цена слова», AUTO_NOW /
  MANUAL, SCHEDULED → ACTIVATING → ACTIVE, NEEDS_ATTENTION.
- Модуль `core` — чистый Kotlin без Android (серии, Restart, кошелёк, FLEX,
  время запуска, доверенный выход, экстренные номера) с тестами. Его можно
  подключить к iOS через Kotlin Multiplatform (один код и одни тесты для обеих
  платформ) или переписать на Swift.

## Чем iPhone отличается (нужны решения до разработки)

На iOS нет механизмов, на которых построена строгая защита Android: экрана
поверх всех приложений, стража через специальные возможности, администратора
устройства, контроля исходящих звонков, тихой отправки SMS.

1. **Блокировка.** Единственный разрешённый способ — Screen Time API
   (FamilyControls, ManagedSettings, DeviceActivity): «щиты» на выбранные
   приложения, категории и сайты по расписанию. Весь телефон заблокировать
   нельзя; «Телефон» и экстренные вызовы iOS всегда оставляет доступными.
2. **Обход.** Пользователь может отозвать доступ Screen Time в Настройках.
   Удаление приложения на время блокировки, по документации, можно запретить
   (ManagedSettings) — проверить на устройстве. Нужно решить, чем считается
   отзыв доступа: NEEDS_ATTENTION до ACTIVE, а в ACTIVE — срыв или нет.
3. **Код доверенному контакту.** iOS не даёт приложению отправить SMS без
   пользователя: системное окно показывает текст сообщения, то есть сам код.
   Для доверенного выхода нужен сервер (SMS-шлюз) или другой канал.
4. **Разрешение Apple.** Для публикации нужно право Family Controls
   (`com.apple.developer.family-controls`), его выдаёт Apple по заявке.
5. **Сборка и установка.** iOS-приложение собирается только на Mac в Xcode;
   в CI — macOS-раннеры GitHub Actions. На iPhone — через Apple Developer
   аккаунт (TestFlight).
6. **Оплата.** Restart и FLEX в App Store — через StoreKit (покупки внутри
   приложения); правила Apple для внутреннего баланса и «Цены слова» — отдельно
   проверить до подключения реальных платежей.

## Предлагаемая структура

- `core` → Kotlin Multiplatform: тот же код и тесты, XCFramework для iOS.
- `ios/` → приложение на SwiftUI + расширения Screen Time
  (DeviceActivityMonitor, ShieldConfiguration).
- CI: отдельный job на macOS — тесты `core`, сборка iOS-приложения.

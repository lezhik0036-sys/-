# MAMA Android — Project Overview

> Резервная документация (backup-context). Составлена из исходного кода,
> существующих `docs/` и истории сессии разработки. Факты, которые не удалось
> подтвердить по коду, помечены **⚠ Требует проверки**.
> Канонический источник по бизнес-логике — `docs/CORE.md` и `docs/MONETIZATION.md`.

## Что это

MAMA — Android-приложение для **добровольной строгой блокировки телефона** на
выбранное время. Блокировку нельзя снять «через минуту»: она переживает
перезагрузку и перевод часов, а выйти раньше можно только с кодом от доверенного
человека.

Первый сценарий — **сон**. Ядро универсально (`SessionMode`): работа, учёба,
дети, цифровой детокс.

Платформа — **только Android**: там можно сделать строгую блокировку без root
(наложение поверх всех приложений + служба спец. возможностей + Device Admin).
iOS-версия — отдельный проект (`mama-ios`), к этому репозиторию отношения не
имеет.

## Цели

- Помочь человеку сдержать собственное решение «отключиться», сделав ранний
  срыв осознанным и трудным, но не опасным.
- Блокировка строгая: переживает перезагрузку, перевод часов, попытки закрыть
  через «Домой»/«Назад»/«Недавние» и быстрое удаление приложения.
- Ранний выход — только через доверенный контакт: он получает SMS с 5-значным
  кодом и решает, диктовать ли его. На ввод — 3 попытки.
- Безопасность превыше всего: экстренные вызовы и входящие звонки всегда
  доступны; разблокировка телефона никогда не зависит от оплаты.

## Ключевые функции

| Функция | Суть | Источник правды |
|---|---|---|
| Строгая блокировка | Оверлей + foreground-служба + Accessibility-страж + Device Admin + ClockGuard | `docs/CORE.md` §3 |
| Trusted Exit | Ранний выход по коду доверенного контакта, **бесплатно**. Код генерит/хранит/проверяет backend; телефон правильный код не видит | `docs/CORE.md`, `backend/` |
| Серии 3/5/7 | 3, 5 или 7 ночей подряд с одним окном | `core/Series.kt`, `SeriesFlow.kt` |
| Restart | Платный перезапуск сорванной серии: 99 ₽ (3д) / 179 ₽ (5д) / 299 ₽ (7д) | `core/Series.kt` (`restartPriceRub`) |
| FLEX | Пакет из 7 периодов на любые дни в течение 30 дней, 349 ₽ | `core/Programs.kt` (`FlexPackage.PRICE_RUB`) |
| «Цена слова» | Добровольная внутренняя ставка (100–100 000 ₽ из внутреннего баланса), часть возвращается | `core/Wallet.kt`, `docs/MONETIZATION.md` |
| 30-дневный cooldown | После срыва бесплатный старт — только через 30 дней (или платный Restart) | `core/Programs.kt` (`StandardRules`) |
| Guardian | Строгая защита во время блокировки (страж + Device Admin) | `app/lock/GuardService.kt` |
| Тестовый режим | 15-минутная блокировка; в debug-сборке лок капится 15 мин и показывается TEST CODE | `core/TestMode.kt`, `FeatureFlags.TEST_MODE` |

Деньги **никогда** не разблокируют телефон. Платные только Restart и FLEX.
Подробная монетизация — `docs/MONETIZATION.md`.

## Пользовательские сценарии

1. **Настройка.** Режим → окно «с/до» и часовой пояс → доверенный контакт
   (имя + номер) → «Цена слова» (опц.) → чек-лист разрешений → «Запустить MAMA».
   До начала блокировку можно отменить.
2. **Блокировка активна.** На экране остаются таймер («День N из M» / FLEX /
   тестовый режим), «Попросить код», звонок контакту, экстренные службы.
   Любой переход в другое приложение возвращает на экран MAMA.
3. **Ранний выход (Trusted Exit).** «Мне действительно нужно выйти» → запрос
   кода → backend отправляет SMS контакту → ввод кода (3 попытки) → серия
   завершается через `LockEngine.endByTrustedExit` (бесплатно). Нет сети —
   честная ошибка, попытка не тратится.
4. **Срыв.** Если ночь не доведена — серия `BROKEN`. Экран «Срыв — часть пути»:
   личная причина пользователя, «Цена слова» и предложение Restart.
5. **Restart / новый старт.** Платный перезапуск той же длины с новым окном,
   либо бесплатный старт после 30-дневного ожидания.
6. **Экстренный доступ.** Аварийно телефон открывается на 15 минут, затем
   блокировка возвращается (безопасность). Экстренные номера — всегда.

# MAMA Android — Development History

> Backup-context. Сводка ключевых решений по истории git и сессии разработки.
> Это не полный changelog — подробное обоснование бизнес-логики в `docs/CORE.md`
> и `docs/MONETIZATION.md`, коммиты см. `git log`.

## Фундаментальные решения

- **Разделение `:core` / `:app`.** Вся логика (расписание, часовые пояса, коды,
  серии, кошелёк, восстановление) — в чистом Kotlin-ядре с тестами. Android-слой
  только исполняет решения ядра. Причина: детерминизм, тестируемость без эмулятора,
  переносимость ядра.
- **Строгая блокировка без root.** Многослойная защита (оверлей + foreground-служба
  + Accessibility-страж + Device Admin + ClockGuard). Причина: на Android это
  единственный способ сделать блокировку, которую нельзя тривиально снять, не
  требуя root и не нарушая безопасность (экстренные вызовы всегда доступны).
- **Доверенное время (`ClockGuard`).** Перевод системных часов не укорачивает
  блокировку (anchor + elapsedRealtime + bootId). Причина: очевидный обход.
- **Фасад `Mama.kt`.** Единственная точка входа Android→ядро, всё под одним
  замком, на свежезагруженном состоянии. Причина: исключить гонки и рассинхрон.

## Монетизация и серии (см. `docs/MONETIZATION.md`)

- **Серии 3/5/7**, статус-машина `SCHEDULED→ACTIVATING→ACTIVE→COMPLETED/BROKEN`,
  обязательной серия становится только при `strictProtectionReady`.
- **Цены зафиксированы** (коммит `4141f42`): Restart 99/179/299 ₽, FLEX 349 ₽.
  Источник правды — `core/Series.kt` и `core/Programs.kt`, не хардкод в UI.
- **30-дневный cooldown** после срыва; во время cooldown возможен платный Restart
  (`a30d0b6`), правило «re-anchor на каждый срыв» закреплено тестами (`13095da`).
- **«Копилка»/приоритеты старта**: завершённый платный Restart даёт бесплатную
  серию той же длины (`9aaa367`), приоритет «копилка над Restart» (`2b7cb1c`),
  единый money-only резолвер источника старта для всех точек входа (`ffe4ce6`,
  `c89fd45`). Завершённая серия очищает `standardFailedAt` — реабилитация (`cc8994c`).
- **«Цена слова»** — добровольная внутренняя ставка из внутреннего баланса,
  часть возвращается (`core/Wallet.kt`).

## Trusted Exit → server-authoritative

- Сначала код слал сам телефон по SMS; затем доставка вынесена за seam (`fc9f330`),
  далее — **полный переход на server-authoritative** (`0339341`): backend владеет
  кодом, телефон хранит только handle. Robolectric-тесты починены под новую модель
  (`b188860`).
- **TEST-safety net** (`afd3b34`, `afb...`): в debug-сборке каждый лок капится
  15 минутами, показывается TEST CODE, есть readiness-check — чтобы тестовое
  устройство не осталось заблокированным.
- **Safety-gate для Trusted Exit в TEST MODE** как release-gate для `*-test` APK
  (`f938959`), затем заметный нескрываемый TEST CODE-баннер (P0, `67cf9e2`).
- **Backend (Ktor), 3 фазы:**
  - Фаза 1 (`aed03c8`): движок challenge + API + тесты + mock SMS.
  - Фаза 2 (`e3a0a8e`): реальный `SmsRuProvider`, жёсткий TEST/PROD split.
  - Фаза 2.1 (`77003ef`): безопасная smoke-отправка одной SMS.
  - Финализация SMS.RU (`25897f7`): env `MAMA_SMSRU_API_ID`, точный текст,
    хранение `sms_id`, `/ready`.
  - Docker-деплой (`4d49eb7`): Dockerfile + compose + Caddy (HTTPS) + `DEPLOY.md`.

## UI / дизайн

- Эволюция «природной» дизайн-системы (серия коммитов `e5d897c`…`a0ae25b`),
  затем **канонический UI V1**: onboarding, «Срыв», «День N из M», «Время для
  себя» (`4bbd3f0`), rich-карточки выбора серии «Выбери путь» 2×2 (`68e7fa5`,
  `135dd77`), богатый экран «Как работает MAMA» (`dfdb707`, `72ba844`).
- **Финальный UI-pass** (`cf00365`): главные CTA — жирный sans (не serif),
  на активном локе инфоблок-цитата визуально отделён от кнопок «Экстренный вызов»
  и «Мне действительно нужно выйти», на экране срыва — один эмоциональный блок
  (личная причина). Бизнес-логику не трогали.

## Полевой тест

- Чек-лист и фиксы под Samsung/One UI (`dad9d95`, `docs/FIELD_TEST_01_SAMSUNG.md`,
  `docs/STATUS.md`). Функциональная цепочка прошла реальный Samsung-тест (по словам
  пользователя в сессии; **⚠ формального отчёта в репозитории за текущую версию нет**).

## Принцип, проходящий через всю историю

Бизнес-логику (Trusted Exit, Series/Restart/FLEX, «Цена слова», 30-дневный
cooldown, Guardian, блокировку, цены, тестовый safety-net) **не меняют ради UI
или рефакторинга**. Изменения вносятся минимальными изолированными шагами с
зелёным CI.

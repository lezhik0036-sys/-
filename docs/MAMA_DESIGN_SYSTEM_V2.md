# MAMA Design System v2

**Source of truth для всего дальнейшего UI MAMA.** Экраны переносятся на v2
по одному, после утверждения; пока экран не перенесён, он остаётся на
`docs/DESIGN_SYSTEM_V1.md`. Визуальный редизайн никогда не меняет
product/core logic (см. «Что не меняется»).

Главный эмоциональный визуальный reference — утверждённый Welcome-арт:
`docs/design-reference/welcome_v2_mockup.webp` (MAMA и разные категории
пользователей).

## Характер интерфейса

MAMA воспринимается как **заботливый контроль + спокойствие + уверенность +
лёгкий юмор**.

Не как: родительский контроль · медицинское приложение · наказание ·
банковский интерфейс · агрессивный blocker.

Минимум красного и тревожных состояний: ни красных экранов, ни
предупреждающих значков, ни слов «провал», «ошибка», «проигрыш».

## Компоненты (`ui/design/DesignKitV2.kt`)

- `primary` — главное действие: коралловая «таблетка», белый текст, «→».
  Одно на экран.
- `secondary` — второе действие: светлая таблетка с песочной обводкой, текст
  deep olive.
- `link` — тихое текстовое действие («Мой путь», «Посмотреть мой путь»).
- `quietAction` — всегда доступное, но не главное действие (блокировка:
  «Экстренный звонок», «Мне действительно нужно выйти»).
- `pill` — статус («Пройдено ночей: 4 из 7»), light olive.
- `card`, `note` — мягкие карточки и карточки фактов (тёплый вариант — для
  «Цены слова»).
- `timerRing` — таймер блокировки: светлый диск, трек light olive, дуга olive,
  день серии плашкой.
- `portrait` — MAMA круглым портретом с мягким коралловым ореолом.
- `page` — молочная страница: тёплый градиент вниз, мягкие круги light coral
  и light olive, две веточки по краям (как на Welcome-арте).

## Фирменный персонаж — MAMA

Взрослая женщина примерно 40–50 лет, каре, чёрный смокинг, белая рубашка и
бабочка. Спокойная, уверенная, слегка ироничная, доброжелательная.

Персонаж **не** на каждом экране:

| Экран | MAMA |
|---|---|
| Welcome | крупно — утверждённый арт |
| Recovery | поддерживающая версия |
| Success | праздничная версия |
| Trusted Exit / Restart | небольшая |
| Statistics / Settings | преимущественно чистый интерфейс, без большого персонажа |
| ACTIVE (блокировка) | без персонажа: главный объект — таймер и день серии |

## Правила экранов

**Welcome**

- «Добро пожаловать в MAMA» («MAMA» — коралловым)
- «Ты уже сделал важный шаг — выбрал больше времени для настоящей жизни.»
- «MAMA поможет сохранить решение, когда вечером захочется его отменить.»
- «Один вечер. Одно решение. Начнём.»
- Primary CTA: **«Начать свой путь →»**; secondary: **«Мой путь»**.
- Текст и кнопки — нативные; арт — отдельный вид во всю ширину, целиком до
  своей волны. На коротком экране текст прокручивается под кнопкой и
  мягко затухает.

**ACTIVE (блокировка)** — максимально спокойно. Главный объект — таймер и
день серии. «Экстренный звонок» и «Мне действительно нужно выйти» (Trusted
Exit) — тихие secondary actions.

**Recovery** — никаких красных экранов, warning icons, «провал», «ошибка»,
«проигрыш». Основная формулировка: **«Этот путь продолжается.»** Поддержка:
**«Один сложный вечер не отменяет твоего решения.»** Restart — естественное
продолжение пути, единственное главное действие. Возврат 50 % «Цены слова»
заранее не упоминается.

## Что не меняется

Визуальный редизайн не трогает: STANDARD 3/5/7 · FLEX · Restart · Trusted
Exit · 3 попытки кода · Emergency Calls · AUTO_NOW / MANUAL · правило 30
дней · test credits · тестовые 15 минут · SeriesHistory · существующие
переходы состояний.

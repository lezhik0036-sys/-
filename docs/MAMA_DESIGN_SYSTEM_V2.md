# MAMA Design System v2 — «природа / земля / MAMA как тихая поддержка»

**Source of truth для всего UI MAMA.** Весь интерфейс говорит на одном языке:
цвета, страница, карточки, кнопки, шрифт, иконки, отступы, состояния и
фото-окна берутся отсюда. Визуальный редизайн никогда не меняет
product/core logic (см. «Что не меняется»).

Один визуальный мир: production-фото природы (`assets/scenes/v1/`) в
одной обработке и земляная страница под ними. Иллюстраций и персонажа в
интерфейсе нет — главный образ бренда природа.

## Бренд-идея

**MAMA — тихая опора, как земля под ногами.** Земля держит, природа не
давит, а поддерживает. MAMA — не контроль и не наказание, а ритм,
восстановление и устойчивость.

Не «эзотерика» и не «открытка»: спокойная, заземлённая, тёплая, живая,
поддерживающая среда.

## Тон

Тёплый · спокойный · заземлённый · мягкий · безопасный. Без лозунгов,
давления, тревоги. Ко всему пользователю — на «ты», спокойно и уважительно
(SMS доверенному контакту — на «Вы»: оно адресовано не пользователю).

Не: родительский контроль · медицинское приложение · наказание · банк ·
агрессивный blocker. Ни красных экранов, ни предупреждающих значков, ни
слов «провал», «ошибка», «проигрыш».

## Метафоры интерфейса

| Что | Как это выглядит |
|---|---|
| Земля держит | у каждой страницы внизу — «земля»: низкие холмы светлой оливы, шалфея и песка, на них две веточки |
| Природа — среда, не декор | фото-«окно в природу» сверху: приглушено туманом, заканчивается мягкой волной |
| Прогресс — путь, энергия растёт | шаги пути (сегменты от глубокой оливы к шалфею, впереди — песок); свет: тихое утро → живой день → светлый вечер |
| Начало — рассвет | Welcome и онбординг: один рассвет над озером, свет разгорается от страницы к странице |
| Блокировка — тихая рамка | самая тихая страница: таймер — молочный диск, как солнце над землёй; два тихих действия |
| Recovery — возвращение на путь | тропа к озеру на рассвете, «Этот путь продолжается», Restart — естественное продолжение |
| Success — внутренняя победа | самый светлый экран: простор, солнце над озером, пройденный путь; без конфетти |
| Trusted Exit / Restart — уважение | тихое туманное утро: нейтрально, ни наказания, ни праздника |
| Мотивация — мягкая поддержка | одна тихая мысль на Manrope над фото этапа серии |

## Типографика

Только **Manrope** (`assets/fonts/Manrope.ttf`, вариативный), цитаты тоже —
у интерфейса один голос. Шкала — `Typo`: заголовок экрана 31 sp ExtraBold,
подзаголовок 17, текст 15, подписи 13.5, кнопки 16–17 Bold, мысль (цитата,
мотивация) 19 sp SemiBold, на экране мотивации — 28 sp. Антиква удалена.

## Страница и фото-окна

- **`EarthPage`** (`ui/design/EarthPage.kt`) — страница каждого экрана:
  молоко → тёплый вниз, два мягких круга (светлая глина, светлая олива),
  «земля» из четырёх низких холмов и две веточки. На настройках (без
  фото, с нижней панелью) земли нет — её закрыла бы панель.
- **Тихая страница** (`EarthPage(quiet = true)`) — только для ACTIVE и
  экстренных служб: без кругов и веточек, две бледные линии земли.
- **Фото-окно** (`ScenicBackground`) — production-фото природы: приглушённые
  цвета, молочный подъём, туман, густеющий к земле; внизу мягкая волна, под
  ней — та же `EarthPage`. Фото не перерисовывается.

### Свет (`SceneMood`)

| Свет | Насыщенность · подъём · туман | Где |
|---|---|---|
| `QUIET` — тихий | 66 % · 20 % · густой | начало серии, до неё, Trusted Exit, Restart, онбординг 1, «Твой путь только начинается» |
| `CALM` — спокойный | 78 % · 14 % · обычный | середина серии, мастер, FLEX, Recovery, онбординг 2 |
| `BRIGHT` — светлый | 94 % · 7 % · лёгкий | конец серии, Success, онбординг 3 |

| Состояние | Фото | Свет |
|---|---|---|
| Welcome (+ онбординг) | `dawn` — тихий рассвет над озером (`assets/art/welcome_dawn.webp` — окно Welcome) | тихий → светлый |

## Компоненты (`ui/design/DesignKit.kt`)

- `primaryButton` — одно главное действие экрана: матовая глиняная
  «таблетка», белый текст, «→», мягкое глиняное свечение.
- `secondaryButton` — второе действие: молочная таблетка с песочной
  обводкой, текст глубокой оливы.
- `linkButton` — тихое текстовое действие («Мой путь», «Отменить запуск»).
- `quietAction` — всегда доступное, но не главное (блокировка).
- `chip`, `selectableCard` — выбор: туман + оливковая обводка, круг
  заполнен глубокой оливой, галочка.
- `badge`, `tag` — статус и метка: светлая олива, полностью круглые.
- `card`, `quietCard`, `summaryCard`, `rowsCard`, `noteCard` (INFO — олива,
  CARE — тёплая земля и глина), `quoteCard` (Manrope, кавычки шалфея или
  земли).
- `segments` — шаги пути; `timerRing` — таймер: молочный диск, трек
  светлой оливы, дуга шалфей → олива, день серии плашкой.
- `bottomNav` — молочная панель, выбранный раздел — светлая олива.
- `DesignKitV2` — то, что нужно только героям-экранам: акцент «MAMA» и
  `EarthPage` (тихая — для блокировки); остальное — те же компоненты.
- Старый набор `Kit` (разрешения, выбор серии, причина, настройки, план
  FLEX, пикеры, листы оплаты) собран из этих же компонентов.

## Правила экранов

**Welcome** — тихий рассвет над озером; «Добро пожаловать в MAMA» («MAMA» —
глиной), «Ты уже сделал важный шаг — выбрал больше времени для настоящей
жизни.», «MAMA поможет сохранить решение, когда вечером захочется его
отменить.», «Один вечер. Одно решение. Начнём.»; «Начать свой путь →»,
«Мой путь».

**Онбординг** — три страницы один раз перед первым использованием, между
Welcome и существующей настройкой (дальше — как раньше: разрешения, выбор
серии). Рассвет Welcome продолжается, свет разгорается; страницы — шаги пути
«1 из 3»; «Далее».
1. «Тебе не нужно становиться сильнее. Тебе нужен ритм.»
2. «Днём ты принимаешь решение. Ночью MAMA помогает его сохранить.»
3. «Начнём с нескольких ночей.»

**ACTIVE (блокировка)** — самый спокойный и минималистичный экран: тихая
страница, фраза, «Телефон под защитой до …», таймер (время и день серии,
без значка), два тихих действия. «Экстренные службы» — на той же странице.

**Trusted Exit** («Досрочный выход», ввод кода) — тихое туманное утро:
спокойно, уважительно, нейтрально.

**Recovery** — возвращение на путь: тропа к озеру на рассвете, «Этот путь
продолжается.», «Один сложный вечер не отменяет твоего решения.», плашка
пройденных ночей. Restart — единственное главное действие. Ни красного, ни
тревоги. Возврат 50 % «Цены слова» заранее не упоминается.

**Restart** (время, «Цена слова») — тихое утро, как Trusted Exit.

**Success** — самый светлый экран: простор и солнце, «Ты сделал это.»
крупно, результат, «Цена слова» сохранена, «Новая серия». Без конфетти.

## Что не меняется

Визуальный редизайн не трогает: STANDARD 3/5/7 · FLEX · Restart · Trusted
Exit · 3 попытки кода · Emergency Calls · AUTO_NOW / MANUAL · правило 30
дней · test credits · тестовые 15 минут · SeriesHistory · модель данных и
хранение · расчёты · навигацию · существующие переходы состояний · тексты
(кроме согласованных) · тесты.

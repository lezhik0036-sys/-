# MAMA Design System v2 — «природа / земля / мать»

**Source of truth для всего UI MAMA.** Весь интерфейс говорит на одном языке:
цвета, страница, карточки, кнопки, шрифт, иконки, отступы, состояния и
фото-окна берутся отсюда. Визуальный редизайн никогда не меняет
product/core logic (см. «Что не меняется»).

Главные визуальные референсы — утверждённый Welcome-арт
(`docs/design-reference/welcome_v2_mockup.webp`) и production-фото природы
(`assets/scenes/v1/`).

## Бренд-идея

**MAMA — тихая опора, как земля под ногами.** Земля держит, природа не
давит, а поддерживает. MAMA — не контроль и не наказание, а ритм,
восстановление и устойчивость.

Не «эзотерика» и не «открытка»: спокойная, заземлённая, тёплая, живая,
поддерживающая среда.

## Тон

Тёплый · спокойный · заземлённый · мягкий · безопасный. Немного
доброжелательной иронии. Без лозунгов, давления, тревоги.

Не: родительский контроль · медицинское приложение · наказание · банк ·
агрессивный blocker. Ни красных экранов, ни предупреждающих значков, ни
слов «провал», «ошибка», «проигрыш».

## Метафоры интерфейса

| Что | Как это выглядит |
|---|---|
| Земля держит | у каждой страницы внизу — «земля»: низкие холмы светлой оливы, шалфея и песка, на них две веточки |
| Природа — среда, не декор | фото-«окно в природу» сверху: приглушено туманом, заканчивается мягкой волной, как Welcome-арт |
| Прогресс — путь и ритм | шаги пути: сегменты от глубокой оливы к шалфею, впереди — песок |
| Блокировка — тихая рамка | таймер — молочный диск, как солнце над землёй; два тихих действия |
| Recovery — возвращение в ритм | «Этот путь продолжается», Restart — естественное продолжение |
| Success — признание пути | спокойный вечер, результат, без конфетти и значков |
| Мотивация — мягкая поддержка | одна тихая мысль на Manrope над туманным фото |

## Типографика

Только **Manrope** (`assets/fonts/Manrope.ttf`, вариативный), цитаты тоже —
у интерфейса один голос. Шкала — `Typo`: заголовок экрана 31 sp ExtraBold,
подзаголовок 17, текст 15, подписи 13.5, кнопки 16–17 Bold, мысль (цитата,
мотивация) 19 sp SemiBold, на экране мотивации — 28 sp. Антиква удалена.

## Страница и фото-окна

- **`EarthPage`** (`ui/design/EarthPage.kt`) — страница каждого экрана:
  молоко → тёплый вниз, два мягких круга (светлая глина, светлая олива),
  «земля» из четырёх низких холмов и две веточки. На настройках (без
  фото, с нижней панелью) земли нет — её закрыла бы панель.
- **Фото-окно** (`ScenicBackground`) — production-фото природы: приглушённые
  цвета (78 % насыщенности), молочный подъём 14 %, туман, густеющий к
  земле; внизу мягкая волна, под ней — та же `EarthPage`. Фото не
  перерисовывается.
- Утро → день → вечер по трети серии (главная), вечер — Success, статистика
  и итог FLEX, путь к озеру — Restart.

## Компоненты (`ui/design/DesignKit.kt`)

- `primaryButton` — одно главное действие экрана: матовая глиняная
  «таблетка», белый текст, «→», мягкое глиняное свечение.
- `secondaryButton` — второе действие: молочная таблетка с песочной
  обводкой, текст глубокой оливы.
- `linkButton` — тихое текстовое действие («Мой путь», «Отменить запуск»).
- `quietAction` — всегда доступное, но не главное (блокировка).
- `chip`, `selectableCard` — выбор: туман + оливковая обводка, круг
  заполнен глубокой оливой, галочка.
- `badge`, `tag` — статус и метка: светлая олива, полностью круглые.
- `card`, `quietCard`, `summaryCard`, `rowsCard`, `noteCard` (INFO — олива,
  CARE — тёплая земля и глина), `quoteCard` (Manrope, кавычки шалфея или
  земли).
- `segments` — шаги пути; `timerRing` — таймер: молочный диск, трек
  светлой оливы, дуга шалфей → олива, день серии плашкой.
- `bottomNav` — молочная панель, выбранный раздел — светлая олива.
- `DesignKitV2` — то, что нужно только героям-экранам: акцент «MAMA»,
  портрет MAMA, `EarthPage`; остальное — те же компоненты.
- Старый набор `Kit` (разрешения, выбор серии, причина, настройки, план
  FLEX, пикеры, листы оплаты) собран из этих же компонентов.

## Фирменный персонаж — MAMA

Взрослая женщина примерно 40–50 лет, каре, чёрный смокинг, белая рубашка и
бабочка. Спокойная, уверенная, слегка ироничная, доброжелательная.

| Экран | MAMA |
|---|---|
| Welcome | крупно — утверждённый арт |
| Recovery | поддерживающая версия (сейчас — круглый портрет из арта) |
| Success | праздничная версия (нужна иллюстрация) |
| Trusted Exit / Restart | небольшая (нужна иллюстрация) |
| Statistics / Settings | чистый интерфейс, без большого персонажа |
| ACTIVE (блокировка) | без персонажа: главный объект — таймер и день серии |

## Правила экранов

**Welcome** — «Добро пожаловать в MAMA» («MAMA» — глиной), «Ты уже сделал
важный шаг — выбрал больше времени для настоящей жизни.», «MAMA поможет
сохранить решение, когда вечером захочется его отменить.», «Один вечер.
Одно решение. Начнём.»; «Начать свой путь →», «Мой путь».

**ACTIVE (блокировка)** — максимально спокойно. Главный объект — таймер и
день серии. «Экстренный звонок» и «Мне действительно нужно выйти» — тихие
действия. Страницы «Экстренные службы», «Досрочный выход» и ввод кода
стоят на той же странице.

**Recovery** — «Этот путь продолжается.», «Один сложный вечер не отменяет
твоего решения.» Restart — единственное главное действие. Возврат 50 %
«Цены слова» заранее не упоминается.

**Success** — спокойное признание пройденного пути: результат, «Цена
слова» сохранена, «Новая серия».

## Что не меняется

Визуальный редизайн не трогает: STANDARD 3/5/7 · FLEX · Restart · Trusted
Exit · 3 попытки кода · Emergency Calls · AUTO_NOW / MANUAL · правило 30
дней · test credits · тестовые 15 минут · SeriesHistory · модель данных и
хранение · расчёты · навигацию · существующие переходы состояний · тексты
(кроме согласованных) · тесты.

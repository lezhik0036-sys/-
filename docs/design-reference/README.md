# Референсы интерфейса MAMA (UI v1)

Здесь лежат **утверждённые владельцем продукта** изображения-референсы
интерфейса MAMA. Они — **source of truth для MAMA UI v1**: новый
Android-интерфейс должен быть визуально максимально близок к ним
(композиция, настроение, цвет, фотографии, размеры карточек, скругления,
типографика, воздух, положение элементов, кнопки, эмоциональный тон).
Не стандартный Material Design.

## Правила

- Сюда попадают только изображения, которые владелец продукта утвердил.
  Файлы хранятся как есть, без пересжатия и правок.
- Референс задаёт внешний вид. Продуктовые правила, цены и тексты условий —
  из `docs/MONETIZATION.md` и `docs/CORE.md`, а не из текста на картинке.
  Работающую функцию, которой нет на референсе, не убираем: переносим её в
  этот визуальный стиль (см. `docs/DESIGN_SYSTEM_V1.md`, «Адаптация»).
- Имя файла: `NN-<ключ>.<расширение>` — номер и ключ экрана из
  `docs/SCREEN_MAP_V1.md` (номер = порядок в CI-туре скриншотов).
  Экран, которого в приложении пока нет: `new-<ключ>`. Несколько вариантов
  одного экрана: `-a`, `-b`. Общие элементы: `00-<что>`.
- Формат — исходный (сейчас WebP, 941 × 1672).
- Референсы — образец внешнего вида, а не production-изображения: фон и
  фото из них не вырезаются и фоном не ставятся. Временные фоны —
  `ScenicBackground` (см. `docs/DESIGN_SYSTEM_V1.md`, §7), production-фоны
  владелец продукта пришлёт отдельно.
- Суммы, цифры статистики и кнопки на картинках продуктовыми правилами не
  являются (решения — `docs/DESIGN_SYSTEM_V1.md`, §12).

# Референсы интерфейса MAMA (UI v1)

Здесь лежат **утверждённые владельцем продукта** изображения-референсы
интерфейса MAMA для редизайна Android-приложения (ветка `claude/mama-ui-v1`).

## Правила

- Сюда попадают только изображения, которые владелец продукта утвердил.
  Черновики и варианты сюда не кладём.
- Референс задаёт внешний вид. Продуктовые правила, цены и тексты условий —
  из `docs/MONETIZATION.md` и `docs/CORE.md`, а не из текста на картинке.
- Имя файла: `NN-<ключ-экрана>.png` (или `.jpg`), где ключ — из
  `docs/SCREEN_MAP_V1.md`, например `01-welcome.png`, `16-lock.png`.
  Несколько вариантов одного экрана: `16-lock-a.png`, `16-lock-b.png`.
- Общие элементы (палитра, кнопки, карточки, иконки) — `00-<что>.png`,
  например `00-palette.png`.
- После добавления референса экран отмечается в `docs/SCREEN_MAP_V1.md`.

Пока референсов нет.

# MAMA — дизайн-система UI v1 (Android)

**Статус: заготовка.** Разделы заполняются по утверждённым референсам из
`docs/design-reference/`. Пока ничего в интерфейсе не меняется.

- Ветка: `claude/mama-ui-v1`, создана от стабильной Android-версии v0.7.8.
- Текущая (действующая) дизайн-система — `docs/DESIGN.md`: палитра
  `MamaColors`, встроенные шрифты Manrope и Cormorant Garamond, компоненты
  `Kit`. Этот документ описывает новую версию; что из текущей сохраняется,
  а что заменяется, — решается по референсам.
- Карта экранов — `docs/SCREEN_MAP_V1.md`.

## Границы редизайна

Редизайн меняет только внешний вид. Не меняются:

- продуктовая и бизнес-логика Android (`core/`, `docs/MONETIZATION.md`,
  `docs/CORE.md`): серии 3/5/7, AUTO_NOW / MANUAL, SCHEDULED → ACTIVATING →
  ACTIVE, NEEDS_ATTENTION, Restart, «Цена слова», кошелёк, 30 дней, FLEX,
  доверенный выход, экстренные звонки, защита блокировки;
- тестовый режим 15 минут;
- тестовое пополнение баланса +1 000 ₽ / +5 000 ₽;
- возможность реально расходовать тестовые кредиты на Restart, FLEX и
  «Цену слова»;
- выбор времени — только цифровой; никаких фотографий из интернета.

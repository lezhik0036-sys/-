# MAMA — карта экранов UI v1 (Android)

Перечень всех экранов Android-приложения (основа — v0.7.8) и утверждённые
референсы из `docs/design-reference/` (source of truth для UI v1).
Решения владельца продукта — `docs/DESIGN_SYSTEM_V1.md`, §12.

- Ключ экрана совпадает с именем экрана в режиме предпросмотра
  (`ui/Previews.kt`, `adb shell am start -n app.mama/.ui.MainActivity --es mama.preview <ключ>`).
- Номер — порядок в CI-туре скриншотов: текущий вид экрана — релиз
  `ui-screenshots`, файл `NN-<ключ>.jpg`. Референс лежит как
  `docs/design-reference/NN-<ключ>.webp`, чтобы их было удобно сравнивать.
- Дизайн-система — `docs/DESIGN_SYSTEM_V1.md`.

Статусы: **—** нет референса (делается в общем стиле референсов) ·
**реф** референс утверждён и сохранён · **G1** экран переделан в PHASE 2,
Группа 1 (утверждена) · **G2** — Группа 2 (утверждена; без отдельной команды не меняется) · **готово**
экран переделан и утверждён ·
**FUTURE** не входит в пилот.

## PHASE 2 · Группа 1 и production-фоны

Группа 1 — главный экран и мастер до старта: `dashboard_active` (и все
состояния главной: `dashboard`, `needs_attention`, `restart_scheduled`,
`flex`, `test_session`), `time` (`restart_time`, `time_test`), `contact`,
`commitment` (`restart_commitment`), `review` (`edit`). Без изменений
пока: `welcome`, `permissions`, `series`, `promise`.

| Сцена (`assets/scenes/v1/`) | Экраны |
|---|---|
| `morning.webp` | главная: серия идёт, ACTIVATING, тест 15 минут, FLEX |
| `evening.webp` | главная: серия запланирована, Restart запланирован, «Серия не началась» |
| `day.webp` | время, контакт, «Цена слова», «Всё готово», «Изменить условия» |
| `dawn.webp` | блокировка (`ds_lock_shell`, Группа 2) |
| `recovery.webp` | срыв / Restart (`ds_recovery`, Группа 2) |

Главная Группы 1: день серии, состояние (плашка), одна короткая фраза из
`MotivationCatalog` и крупный таймер; окно, контакт и «Цена слова» —
короткими строками ниже. «Всё готово»: крупно — серия, время, доверенный
контакт, «Цена слова»; первая блокировка, Restart и причина — вторым
уровнем; полный текст условий — по ссылке «Все условия серии».

CI кладёт рядом с скриншотами сравнения с референсами (`vs-<ключ>.jpg`:
`dashboard_active`, `time`, `contact`, `commitment`, `review`) и с фото
сцены (`scene-<ключ>.jpg`: `dashboard_active`, `time`, `dashboard`,
`ds_lock_shell`, `ds_recovery`).

## PHASE 2 · Группа 2: блокировка, прогресс, мотивация, срыв, Restart, успех

Утверждена владельцем продукта вместе с финальным polish (ACTIVE, recovery,
success). Без отдельной команды не меняется. Экран срыва и его Restart
отмечены стабильными тегами `recovery_screen` и `restart_cta`: тесты
находят состояние по ним, а не по тексту на экране.

| Экран | Сцена | Что на экране |
|---|---|---|
| `lock` (ACTIVE, `LockScreenView`) | `dawn.webp` | M A M A, одна спокойная фраза (`LOCK_NIGHT` / `LOCK_DAY`), «Телефон под защитой до 07:00», кольцо «Осталось · 6 ч 12 мин · День 3 из 7» — главный акцент; «Экстренный звонок» и «Мне действительно нужно выйти» — две тихие полупрозрачные кнопки внизу, всегда доступны, но не главное действие; страницы «Экстренные службы» и «Досрочный выход» в том же стиле |
| `progress_early` / `progress_middle` / `progress_final` (главная ACTIVE) | `morning` → `day` → `evening` по трети серии (3 дня: 1 → morning, 2 → day, 3 → evening) | «День N из M», «Пройдено ночей: K из M», таймер до следующей блокировки, одна короткая фраза |

## PHASE 2 · Группа 3A: статистика и история

Данные — только `SeriesHistory` (`docs/CORE.md` §8) и серия или пакет FLEX,
которые идут сейчас; расчёт — `ui/Statistics.kt`.

| Что | Откуда |
|---|---|
| «Ночей пройдено» — главное число | ночи завершённых серий STANDARD + текущей серии; «дней», если окна дневные |
| «Серий завершено» | серии STANDARD с итогом COMPLETED |
| «Лучший результат» | больше всего ночей в одной завершённой серии, при равенстве — пройденная до конца |
| «Продолжил после срыва» | Restart, которые реально начались (`restartOf`); оплаченный, но не начатый — не считается |
| «FLEX-периодов пройдено» | только если есть FLEX: успешные из использованных, число пакетов |
| «Твой путь» | текущая серия («Сейчас»), затем завершённые — новые сверху |

- Строка, которой нечего сказать, не показывается (никаких нулей); без
  истории — пустое состояние без чисел (`morning.webp`, фото целиком).
- С историей — `evening.webp` сверху, под главным числом.
- Не показывается: часы «без телефона», «N дней подряд», проценты,
  рейтинги, сравнения, деньги. Слов BROKEN, FAILED, «провал», «неудача» нет:
  серия, остановившаяся раньше, — «Ты продолжил путь позже», если после неё
  реально что-то началось, иначе «Этот путь продолжается».
- FLEX на карточке — тег FLEX, «Пройдено N периодов», «Использовано M из 7»,
  даты; итог — «Все 7 периодов использованы» или «Срок пакета закончился».
- Теги для тестов: `statistics_screen`, `statistics_empty`, `path_item`.

## Обязательно сохранить при редизайне

- Тестовый режим 15 минут (`time_test`, `test_session`; вход — «Настройки →
  Тестирование»).
- Тестовое пополнение баланса +1 000 ₽ / +5 000 ₽ («Настройки →
  Тестирование») и «+1 000 ₽ · тест» при нехватке средств (`checkout`).

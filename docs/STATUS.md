# Статус тестирования (23.09.2026)

Текущая версия: **v0.1.7** (сборка №9 в GitHub Actions, артефакт `MAMA-v0.1.7`).
Тестовое устройство: Samsung (One UI).

## Работает
- Звонок доверенному контакту — сразу, без набора номера; номер не изменить.
- Входящий звонок — на экране MAMA только «Ответить» / «Завершить».
- Во время звонка экран MAMA остаётся сверху, в приложения не уйти.
- На разблокированном телефоне шторка и «Недавние» закрываются стражем.
- Кнопка «Выдать все разрешения».
- Версия и счётчики стража внизу экрана блокировки.

## Открытые вопросы
- Кнопка специальных возможностей в панели навигации выключает стража.
  Решение — настройки телефона (см. ниже), в приложении не обходим.
- Камера и быстрые настройки на системном экране блокировки Samsung —
  закрываются настройками телефона, в приложении не блокируем.

## Рекомендуемые настройки Samsung перед сессией
1. Спец. возможности → Установленные приложения → MAMA — защита блокировки →
   выключить «Ярлык» (служба остаётся включённой).
2. Спец. возможности → Дополнительные настройки → кнопка спец. возможностей /
   боковая клавиша и громкость — ничего не назначено.
3. Экран блокировки и AOD → Ярлыки — убрать камеру.
4. Дополнительные функции → Боковая клавиша → Двойное нажатие — выключить.
5. Экран блокировки и AOD → Параметры безопасной блокировки →
   «Блокировать сеть и безопасность» — включить.
6. Дисплей → Панель навигации → Жесты проведения, «Подсказки жестов» — выкл.

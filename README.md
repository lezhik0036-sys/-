# MAMA

Приложение для добровольной блокировки телефона на выбранное время. Блокировка
строгая: её нельзя снять через минуту, она переживает перезагрузку, а выйти
раньше можно только с кодом от доверенного человека.

Первый сценарий — сон. Ядро универсальное: работа, учёба, дети, цифровой детокс.

Платформа — **Android**: только там можно сделать строгую блокировку без root.
Подробная спецификация, модель угроз и ограничения описаны в [docs/CORE.md](docs/CORE.md).

## Как это работает

1. Выберите режим, время «с/до» и часовой пояс.
2. Укажите доверенного контакта (имя и номер).
3. Выдайте разрешения из чек-листа и нажмите «Запустить MAMA».
4. До начала блокировку можно отменить. После начала на экране остаются
   только таймер, запрос кода, звонок контакту и экстренные службы.
5. Нужно выйти раньше: нажмите «Попросить код». Контакт получит SMS с кодом из
   5 цифр и решит, диктовать его или нет. На ввод даётся 3 попытки.
   Аварийный доступ открывает телефон на 15 минут, после чего блокировка
   возвращается.

## Структура

```
core/     общая бизнес-логика на Kotlin Multiplatform (Android + iPhone): серии,
          FLEX, Restart, «Цена слова», кошелёк, 30 дней, время, доверенный выход (+ тесты)
app/      Android: оверлей, foreground-служба, Accessibility-страж, Device Admin,
          будильники, приёмники загрузки, SMS, экран настройки
iosApp/   iPhone (ветка claude/mama-ios): SwiftUI + Screen Time, см. iosApp/README.md
docs/     спецификация MAMA Core v0.1, монетизация, дизайн-система (DESIGN.md)
```

## Сборка

```bash
./gradlew :core:jvmTest         # общая логика, только JDK 17+
./gradlew :app:assembleDebug    # нужен Android SDK (ANDROID_HOME или local.properties)
```

При каждом push GitHub Actions запускает тесты, собирает debug APK и
прикладывает его к запуску как артефакт `mama-debug-apk`.

## Установка на телефон (debug)

1. Скачайте APK из артефактов CI и установите его.
2. Android 13+: Настройки → Приложения → MAMA → ⋮ → «Разрешить доступ к
   ограниченным настройкам». Без этого не включится служба специальных
   возможностей.
3. Откройте MAMA и пройдите чек-лист разрешений.

Перед первой ночью проверьте короткую сессию на 15 минут с настоящим
контактом.
